# 📋 Clickboard

A lightweight, privacy-first clipboard manager extension for Microsoft Edge, Mozilla Firefox, and Google Chrome.

Clickboard allows you to save text snippets directly to your browser's local storage so you can easily access, edit, and organize them without leaving your current tab.

## ✨ Features

- **⚡ One-Click Copy:** Save and retrieve text snippets instantly.

- **✏️ Edit on the Fly:** Update your saved notes directly within the extension popup.

- **🖐️ Drag-and-Drop Organization:** Rearrange your saved snippets to match your workflow.

- **🔒 100% Private & Offline:** Zero analytics, zero external API calls, and no cloud syncing. All data is strictly stored locally on your device using the browser's native storage API.

## 🛠️ Tech Stack

Built for maximum performance and security without the bloat:

- **Vanilla JavaScript** (No heavy frameworks or build tools)

- **HTML5 & CSS3**

- **Manifest V3** Compliant
